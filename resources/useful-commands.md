# 🛠️ Useful Commands

## Android / Gradle

### Clean project

```bash
gradlew clean
```

### Run unit tests

```bash
gradlew testDebugUnitTest
```

### Build debug APK

```bash
gradlew assembleDebug
```

### Install APK using ADB

```bash
adb install app-debug.apk
```

### Check connected devices

```bash
adb devices
```

# Git

## Check status

```bash
git status
```

## Add files

```bash
git add .
```

## Commit

```bash
git commit -m "feat: add new Android feature"
```

## Push

```bash
git push
```

## Pull latest changes

```bash
git pull
```

## View commits

```bash
git log --oneline
```

## Create a branch

```bash
git checkout -b feature/new-feature
```

## Switch branch

```bash
git checkout main
```

## Merge branch

```bash
git merge feature/new-feature
```
