# 🎓 Student Registration Form

A simple Android application created to practice basic Android development and XML UI design.

## 🛠️ Technologies

* Java
* XML
* Android Studio

## ✨ Features

* Student registration form
* Student name input
* Email input
* Password fields
* Basic form UI
* Register button

## 📚 Concepts Learned

* Android Studio project structure
* XML layouts
* TextView
* EditText
* Button
* LinearLayout
* UI styling
* Basic Android event handling
