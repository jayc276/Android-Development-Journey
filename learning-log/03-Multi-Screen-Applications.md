# 📱 Multi-Screen Applications

At this stage, I moved from basic Android screens to applications containing multiple connected screens.

## 🎯 What I Learned

* Multiple activities
* Screen navigation
* Intent
* Dashboard layouts
* Application flow
* Passing information between screens
* RecyclerView basics
* Organizing application features

## 🛠️ Projects

### Student Management Application

The application included:

* Login
* Registration
* Dashboard
* Profile
* Attendance
* Results
* Courses

### Online Shopping Application

The application included:

* Login
* Registration
* Categories
* Products
* Product details

## 📱 Application Flow

A typical application started looking like:

```text
Login
  ↓
Dashboard
  ↓
Feature
  ↓
Details
```

Instead of:

```text
Single Screen
```

## 🐛 Challenges

I faced challenges such as:

* Managing multiple screens
* Understanding navigation
* Keeping the application flow organized
* Designing reusable layouts
* Managing different UI states

## 📚 What I Learned

I started thinking about an Android application as a complete user journey rather than a collection of individual screens.

## 🎯 Outcome

This stage helped me understand how real applications are structured around user flows and features.
