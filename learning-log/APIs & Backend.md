# 🌐 APIs & Backend

As my Android projects became more complex, I started learning how Android applications communicate with backend systems.

## Topics Learned

* REST APIs
* HTTP requests
* JSON
* GET requests
* POST requests
* Authentication
* JWT
* Retrofit
* OkHttp

## Why APIs Matter

Instead of keeping all application data inside the Android application, an API allows the application to communicate with a backend server.

Typical flow:

```text
Android App
     ↓
Retrofit / HTTP
     ↓
REST API
     ↓
Backend Server
     ↓
Database
```

## Challenges

* API connection errors
* Incorrect endpoints
* Authentication problems
* JSON parsing
* Backend connectivity
* Testing APIs

## Important Lesson

A real-world Android application is often not just an Android project.

It can involve:

```text
Android
   +
Backend
   +
Database
   +
Authentication
   +
API
```

This helped me understand how full-stack applications work.
