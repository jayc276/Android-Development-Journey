# 🚀 Real-World Android Development

At this stage, I started moving toward larger and more realistic Android applications.

## 🎯 Focus

The main focus was learning how different Android technologies work together in a complete application.

## 🛠️ Technologies

I started working with:

* Kotlin
* XML
* MVVM
* ViewModel
* LiveData
* Repository pattern
* Retrofit
* OkHttp
* Room Database
* DataStore
* Navigation Component
* View Binding
* Glide

## 🍔 Main Project — FoodieGo

FoodieGo is a food delivery application designed to simulate a real-world ordering experience.

### Features

* Registration
* Login
* Authentication
* Restaurants
* Food categories
* Food details
* Cart
* Addresses
* Checkout
* Orders
* Order status

## 🏗️ Architecture

I started understanding how different layers work together:

```text
UI
 ↓
ViewModel
 ↓
Repository
 ↓
API / Local Database
 ↓
Backend / Database
```

## 💾 Local Data

I learned how applications can store information locally using:

* Room
* DataStore

## 🌐 Remote Data

I used Retrofit and OkHttp to communicate with backend APIs.
